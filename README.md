# AdbPairingHelper

ADB Pairing Helper is a helper app for [PermissionManagerX](https://github.com/mirfatif/PermissionManagerX), [WhatsRunning](https://github.com/mirfatif/WhatsRunning) and our other apps. Using Android's accessibility feature, it tries to auto-fill the ADB pairing code, which may save you the hassle of typing the code manually.

[Wireless Debugging](https://developer.android.com/tools/adb#connect-to-a-device-over-wi-fi) is available only on Android 11+.

See [ADB Guide](https://mirfatif.github.io/adb-guide/android-11/#pair-svc).
